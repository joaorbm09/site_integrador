## Tabela de Elementos Semânticos HTML5 Utilizados no Projeto

| Elemento | Função e Aplicação no Projeto |
| :--- | :--- |
| **`<header>`** | Cabeçalho principal do portal corporativo e das páginas de cursos (contém logo, título H1 e subtítulo). |
| **`<nav>`** | Menu de navegação principal com suporte a links internos (âncoras) e links para outras páginas do portal. |
| **`<main>`** | Envolve o conteúdo principal da página, otimizando a acessibilidade e semântica para leitores de tela. |
| **`<section>`** | Agrupa blocos temáticos de conteúdo (ex: Quem Somos, Serviços, Notícias, Módulos do Curso). |
| **`<article>`** | Conteúdo autônomo e independente (ex: Cards de Cursos, Artigos de Notícias, Tópicos Específicos). |
| **`<aside>`** | Bloco complementar com avisos, horários, pré-requisitos ou links de cadastro. |
| **`<footer>`** | Rodapé da página com informações de contato, mapa e copyright ©. |
