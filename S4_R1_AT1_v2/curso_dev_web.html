Curso: Desenvolvimento Web & PHP

Aprenda a criar aplicações web dinâmicas, modernas e integradas com banco de dados.

Visão Geral do Curso

O curso traz uma abordagem prática focada nas principais tecnologias do mercado de desenvolvimento web, cobrindo desde a estruturação do site até a lógica de programação backend com PHP.

O que você vai aprender:

  • Estruturação e Semântica em HTML5
  • Estilização e Responsividade com CSS3
  • Lógica de Programação e manipulação de dados com PHP
  • Integração com Bancos de Dados MySQL

Duração e Carga Horária

Duração: 6 meses (240 horas de aula práticas).

Modalidade: Presencial com suporte a projetos práticos de mercado.

Pré-requisitos & Avisos

Requisito: Conhecimentos básicos de informática.

Vagas: Turmas reduzidas para melhor aproveitamento no laboratório.
